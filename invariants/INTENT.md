# Hearth

A home for one agent: a single continuous mind across every conversation,
channel and restart.

Whenever the agent wakes, Hearth keeps one question open: **what am I in the
middle of, and for whom?**

A harness that runs model turns is only half the job. An agent built that way
is many short conversations sharing a name. A reply lands in a thread that never
asked for it. A promise made in one chat is invisible in the next. A plan
disappears when the turn ends. Moving one agent restarts its neighbour. The
agent ends up relaying messages to itself.

Hearth is built on the idea that the agent, not the conversation, is the unit.
It has one identity, one memory it writes itself, and one account of what it
has been asked and what it owes. Conversations are threads it holds, not
separate minds. It lives as itself on its host, so nothing it holds belongs to
anyone else and nothing a neighbour does can stop it. When it can't do
something, it says so where the asker will see it.

If an agent ever drops a request, forgets something it owes, or loses an
intention because of which conversation, channel or restart it happened in,
Hearth has failed at the one thing it exists to do.
